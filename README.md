# 🌍 Travel & Tourism Website (HTML & CSS)

A responsive **Travel & Tourism Landing Page** built using **pure HTML and CSS only**.
This project showcases tourist destinations, travel packages, and a modern booking-style interface with a clean and attractive UI.

The main objective of this project is to practice **responsive web design, flexbox layouts, background images, and modern UI styling** without using JavaScript.

---

## 🚀 Live Demo

- Live Demo: https://staticwebsiteprateek.netlify.app/

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Font Awesome Icons

---

## 📌 Features

- Sticky Navigation Bar
- Hero Section with Background Image
- Popular Destinations Section
- Tour Packages Section
- Image Cards with Hover Effects
- About Section
- Contact Section UI
- Fully Responsive Layout
